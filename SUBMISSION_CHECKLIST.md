# Client Submission Checklist

- [ ] Confirm the selected API belongs to a classmate, not the client developer.
- [ ] Obtain the classmate’s permission and record their name and repository URL.
- [ ] Replace every bracketed field in `README.md`.
- [ ] Name the repository `filipino-cookbook-client-YOUR_SURNAME`.
- [ ] Run the selected API and confirm its CORS policy allows the client.
- [ ] Test with a valid token and an invalid token.
- [ ] Verify the food list, filters, random action, and recipe details.
- [ ] Confirm the token is not present in tracked files or screenshots.
- [ ] Run `npm test`.
- [ ] Refresh the three files in `screenshots/`.
- [ ] Clone the published repository into a fresh folder and follow the README.
